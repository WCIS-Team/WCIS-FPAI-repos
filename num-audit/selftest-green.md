# 绿测件（num-audit 必须 0 FAIL）

正确口径，全部交叉校验对得上；每个派生数都带算式，锚点都写全。

```
payload = 1400
头 = 14(eth) + 20(ip) + 8(udp) + 8(私有分帧头) = 50 B
线上一片 = 8(preamble+SFD) + 50 + 1400(payload) + 4(FCS) + 12(IPG) = 1474 B = 11 792 bit
载荷效率 = 1400 / 1474 = 94.98%
线上原始速率 = 1 Gbit/s ÷ 8 = 125 MB/s
可用 JPEG 字节率 = 125 × 0.9498 ≈ 118.7 MB/s（= 118.7 × 8 ≈ 950 Mbps）
最高包速 = 125 MB/s ÷ 1474 B ≈ 84 803 pps
交叉校验：64 B 最小帧在线上要占 84 B ＝ 672 bit ⇒ 1 Gbit/s ÷ 672 bit = 1 488 100 pps
HDR 状态依次出 14 + 20 + 8 + 8 = 50 字节（FCS 由 MAC 补，不在这 50 里）
```
